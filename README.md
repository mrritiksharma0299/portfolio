# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/mrritiksharma0299/portfolio.git
```

Move into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
